Apartado Explicativo: Fundamentos de Programación Estructurada

Todo lo que necesitas conocer antes de escribir tu primer programa en Python.

1. ¿Qué es la Programación Estructurada?

La programación estructurada es un paradigma que organiza el código en estructuras de control claras y predecibles, evitando saltos incontrolados (como goto). Se basa en tres estructuras fundamentales:

💡 La analogía de la receta de cocina:

  • Secuencia: Los pasos se ejecutan uno tras otro (picar cebolla → sofreír → agregar tomate).
  • Selección (si/no): Decisiones según condiciones (si hay sal → agregar sal; sino → omitir).
  • Iteración (repetir): Acciones que se repiten mientras se cumpla una condición (revolver mientras no espese).

2. Variables, Tipos de Datos y Operadores

Una variable es un espacio en memoria con un nombre que guarda un valor. En Python no hace falta declarar el tipo; se infiere al asignar.

3. Estructuras de Control de Flujo

Secuencia

Instrucciones que se ejecutan en orden, una tras otra.

nombre = input("Nombre: ")
edad = int(input("Edad: "))
print(f"Hola {nombre}, tenés {edad} años")

Selección: if / elif / else

Ejecuta un bloque solo si se cumple una condición.

nota = float(input("Nota: "))
if nota >= 7:
    print("Promocionado")
elif nota >= 4:
    print("Regular")
else:
    print("Libre")

Iteración: while

Repite mientras la condición sea verdadera.

contador = 1
while contador <= 5:
    print(f"Vuelta {contador}")
    contador += 1

Iteración: for

Recorre una secuencia (rango, lista, cadena).

for i in range(1, 6):
    print(f"Vuelta {i}")

nombres = ["Ana", "Luis", "Marta"]
for n in nombres:
    print(n)

4. Funciones: Modularización y Reutilización

Una función es un bloque de código con nombre que realiza una tarea específica. Permite dividir el problema en partes menores, evitar duplicación y facilitar pruebas.

# Definición
def calcular_promedio(notas):
    suma = sum(notas)
    cantidad = len(notas)
    return suma / cantidad

# Uso
mis_notas = [8, 7, 9, 6]
prom = calcular_promedio(mis_notas)
print(f"Promedio: {prom:.2f}")

💡 Partes de una función:

  • def nombre(parametros): Cabecera (entrada).
  • cuerpo: Instrucciones (proceso).
  • return valor: Salida (opcional).

5. Entrada, Salida y Manejo Básico de Errores

Entrada: input()

Lee texto del teclado. Siempre devuelve str.

nombre = input("Nombre: ")
edad = int(input("Edad: "))  # castear a int
altura = float(input("Altura: "))

Salida: print() y f-strings

Muestra información en consola con formato.

print("Hola", nombre)
print(f"Tenés {edad} años y medís {altura}m")

Try / Except

Captura errores para que el programa no se corte.

try:
    edad = int(input("Edad: "))
except ValueError:
    print("¡Debés ingresar un número!")

Consigna Práctica: ¡Construí tu Aplicación de Consola!

Ahora es tu turno de programar. Seguí estos pasos para crear un sistema completo con menú interactivo.

Tu desafío: Sistema de Gestión Simple

El tema es libre: Gestión de tareas, Agenda de contactos, Inventario de videojuegos, Control de gastos, Sistema de notas de alumnos, etc.

📋 Requisitos obligatorios del programa:

  1. Menú principal en bucle (while True): Que muestre opciones y vuelva a mostrar tras cada acción hasta que el usuario elija "Salir".
  2. Al menos 4 opciones funcionales: Ej: 1) Agregar, 2) Listar, 3) Buscar/Eliminar, 4) Estadísticas, 0) Salir.
  3. Uso de funciones: Cada opción del menú debe ser una función separada (def agregar():, def listar():, etc.).
  4. Estructuras de datos: Usar listas (y opcionalmente diccionarios) para guardar los datos en memoria.
  5. Validación de entrada: Usar try/except para manejar errores de tipo (ej: ingresar texto cuando se pide número).
  6. Código limpio y comentado: Nombres de variables y funciones descriptivos, comentarios explicando qué hace cada parte.

Estructura de archivos recomendada:

mi-proyecto-python/
├── main.py           # Punto de entrada (menú principal)
├── funciones.py      # Funciones de cada opción del menú
├── datos.py          # Listas/diccionarios globales (opcional)
└── README.md         # Descripción del proyecto

Esqueleto base para main.py:

# main.py - Programa principal
from funciones import *

def mostrar_menu():
    print("\n" + "="*40)
    print("   MI SISTEMA DE GESTIÓN")
    print("="*40)
    print("1. Agregar elemento")
    print("2. Listar elementos")
    print("3. Buscar / Eliminar")
    print("4. Ver estadísticas")
    print("0. Salir")
    print("-"*40)

def main():
    while True:
        mostrar_menu()
        try:
            opcion = int(input("Elegí una opción: "))
            if opcion == 1:
                agregar()
            elif opcion == 2:
                listar()
            elif opcion == 3:
                buscar_eliminar()
            elif opcion == 4:
                estadisticas()
            elif opcion == 0:
                print("¡Hasta luego!")
                break
            else:
                print("Opción inválida. Probá de nuevo.")
        except ValueError:
            print("Error: Debés ingresar un número.")

if __name__ == "__main__":
    main()

Laboratorio de IA: Generando Código Python con Criterio

No programarás todo desde cero: aprenderás a ser un director de desarrollo utilizando IA con criterio técnico.

¿Cómo pedirle código Python a una IA?

Una Inteligencia Artificial (ChatGPT, Claude, Gemini, Copilot, etc.) te dará mejores resultados mientras más específico y técnico sea tu pedido (prompt).

🤖 Prompt Plantilla para Copiar y Personalizar: 
Actúa como un desarrollador Python senior y docente de programación estructurada.
Voy a crear un sistema de gestión de consola en Python (programación estructurada, sin POO).
El tema es: [Gestión de tareas / Agenda de contactos / Inventario / Lo que elijas].

Estructura deseada:
- main.py: menú principal en while True con try/except
- funciones.py: una función por opción del menú
- datos.py: lista/diccionario global para almacenar en memoria

Requisitos del código:
1. Menú con al menos 4 opciones + salir (0)
2. Cada opción en su propia función con docstring
3. Uso de listas/diccionarios para persistir datos en memoria
3. Validación de entrada con try/except (ValueError, IndexError, etc.)
4. Código limpio: nombres descriptivos (snake_case), comentarios, sin código muerto
5. Docstrings en funciones explicando parámetros y retorno
6. NO uses clases, herencia, decoradores ni librerías externas (solo built-ins)

IMPORTANTE: Comenta cada bloque de código explicando QUÉ hace y POR QUÉ (variables, bucles, condiciones, funciones, manejo de errores).

⚠️ La Regla de Oro del Desarrollador: Criterio Crítico

¡Prohibido hacer Copiar y Pegar a ciegas!

La IA es tu asistente, no el dueño del proyecto. Tu misión de aprendizaje es:

  • Abrir los archivos .py y leer los comentarios y docstrings de la IA.
  • Probar cambiar valores: modifica una condición, agrega un print de depuración, rompe el código a propósito para ver el error y entiende el traceback.
  • Si la IA incluye algo que no comprendes, pregúntale: ¿Por qué usaste lista.append() y no lista += [item]? ¿Qué diferencia hay entre is y ==?
  • Ejecutá el programa paso a paso con python -m pdb main.py o breakpoint() para ver el flujo.

Publicá tu Proyecto en GitHub

Compartí tu código con el mundo y entregá tu trabajo final con un link profesional.

Pasos para publicar tu proyecto Python en minutos:

1

Creá tu cuenta y un nuevo repositorio

Entrá a github.com, iniciá sesión y hacé clic en New repository. Nombralo (ej: mi-sistema-gestion), marcá Public y NO marques "Add a README" (lo harás vos).

2

Subí tus archivos desde la terminal

Abrí la terminal en tu carpeta del proyecto y ejecutá:

git init
git add .
git commit -m "Versión inicial: sistema de gestión completo"
git branch -M main
git remote add origin https://github.com/TU_USUARIO/mi-sistema-gestion.git
git push -u origin main
3

Creá un README.md profesional

En GitHub, clic en Add file → Create new file, nombralo README.md y pegá esta plantilla:

# Nombre de mi Sistema

Breve descripción de qué hace el programa.

## 🚀 Cómo ejecutar
```bash
python main.py
```

## 📋 Funcionalidades
- ✅ Agregar elementos
- ✅ Listar elementos
- ✅ Buscar / Eliminar
- ✅ Estadísticas

## 🛠️ Tecnologías
- Python 3.x (solo librerías estándar)

## 👨‍💻 Autor
Tu Nombre - Curso/Año
4

¡Tu código está online!

Tu repositorio público quedará en:
https://github.com/TU_USUARIO/mi-sistema-gestion
Comparte ese link con tu docente. ¡Cualquiera puede clonar y ejecutar tu programa con git clone ... && python main.py!
